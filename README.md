# About Me

A personal developer portfolio website for Nagaraju Gajarla, built with React and Vite. The site highlights frontend experience, technical skills, project work, and contact information in a polished single-page portfolio layout.

## Highlights

- Responsive single-page portfolio experience
- Sections for About, Skills, Projects, Writing, and Contact
- React + Vite frontend setup
- Clean, modern design tailored for a developer profile
- Includes a downloadable resume in the project source folder

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal (typically http://localhost:5173).

## Production Build

```bash
npm run build
```

This generates a production bundle in the `dist/` folder.

## Preview Production Build

```bash
npm run preview
```
